De MODAL app maakt gebruik van Ollama voor het beheren en gebruiken van AI-modellen. 
Dat betekent dat je in principe alle modellen die door ollma worden ondersteund, kan gebruiken.

Om een model toe te voegen moet je de naam kennen waarmee Ollama het model identificeert. Je kan deze modellen opzoeken in de [modellenbibliotheek van Ollama](https://ollama.com/search).
