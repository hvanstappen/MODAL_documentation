# Roadmap #

Met de eerste fase van het Modal project werd een eerste versie van de Modal-tool opgeleverd (*Minimal Viable Product* of *MVP*).

Niet alle gewenste functies zijn in deze versie al beschikbaar - die staan op een roadmap die mogelijk in de toekomst verder wordt opgenomen:

| Taak                                                                      | prioriteit |
|:--------------------------------------------------------------------------|:--------:|
| Tekstvarianten bepalen                                                    |   **2**  |
| Speech to Text voor audiobestanden                                        |   **1**  |
| Een gebruiker kan zelf een OCR engine selecteren (niet default tesseract) |   **3**  |
| Voer analyse uit op geselecteerde folder                                  |   **2**  |
| Named Entities worden gecorrigeerd o.b.v. een waardenlijst                |    **2** |
| Named Entities worden gekoppeld aan een publieke PID (bv. Wikidata)       |    **2** |
