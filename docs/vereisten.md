
Voor de installatie gelden volgende eisen:

## Software ##
* Docker desktop  
* Browser (Edge, Chrome, Firefox …)  
* Besturingssysteem: de software is getest op volgende besturingssystemen:  
    * Linux Ubuntu 24 LTS  
    * Windows 11, met Windows subsystem for Linux (WSL)
    * macOS (Intel en arm64) 

## Hardware ##
Voor het gebruik van de AI modellen is het sterk aanbevolen een krachtige pc te gebruiken, bij voorkeur met een grafische kaart (GPU). De specificaties hangen sterk af van de gebruikte modellen, de omvang van het te analyseren archief en je geduld. Voor sommige modellen is een GPU sowieso vereist. 

Een voorbeeldconfiguratie is:

* GPU van 12 of bij voorkeur 16GB (of vergelijkbaar unified memory op macOS met arm64 architectuur)  
* minimaal 16 GB RAM geheugen
